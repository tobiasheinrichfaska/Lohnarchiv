Lohnarchiv — Datenmodell

Erzeugt aus src/logic/model.ts, manifest.ts, chain.ts (Stand 2026-11-23). Bei jeder Modelländerung neu erstellen. JSON-Schlüssel sind absichtlich deutsch (Lesbarkeit für Prüfer).

Archiv (persistiert)

Ein passwortgeschütztes ZIP (AES-256) mit dieser Struktur — das Archiv ist kein Prüfungs-Übergabeformat.

Pfad im ZIPInhalt
dokumente/<personalnummer>/<jahr>/<datei>Einzeldokument (PDF mit eingebettetem Zeitstempel, sonst JPEG/BMP/PNG/TIFF)
dokumente/…/<datei>.tsrGetrenntes RFC-3161-Token für Nicht-PDF-Dateien (StampRef.art = getrennt)
manifeste/manifest_NNNN.jsonKanonisches JSON eines Manifest; diese Bytes werden gehasht und gestempelt
manifeste/manifest_NNNN.tsrRFC-3161-Token über den SHA-256 des Manifests
