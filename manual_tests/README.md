# Manuelle Tests — Lohnarchiv

Schritt-für-Schritt-Anleitungen für Personen ohne Programmierkenntnisse. Sie ergänzen die automatischen
Tests und decken ab, was nur am Bildschirm prüfbar ist.

**Stand 2026-11-23:** Es gibt erst eine Platzhalter-Oberfläche. Weitere Testfälle kommen mit den Bildschirmen
(ZIP öffnen, Dokument ablegen, Entfernen mit Begründung, Export, Adobe-Prüfung des PDF-Zeitstempels).

**Start:** `npm run dev` im Projektordner, dann <http://localhost:5178> öffnen.
