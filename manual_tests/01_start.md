# 01 — Programmstart

## MT-01: Seite startet ohne Fehler

**Voraussetzung:** `npm run dev` läuft.

**Schritte**

1. Öffnen Sie <http://localhost:5178> im Browser.
2. Drücken Sie `F12` und wählen Sie den Reiter „Konsole“.

**Erwartet**

- Die Überschrift „Lohnarchiv“ und ein kurzer Hinweistext sind sichtbar.
- Die Konsole zeigt keine roten Fehlermeldungen.
- Hinweis: Mehr kann die Seite derzeit nicht; die Bedienoberfläche folgt.
